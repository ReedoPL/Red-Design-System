# Red design bootstrap

Follow `AGENTS.md` and `DESIGN.md` for all Red visual work. Read `colors_and_type.css`, `brand/voice.md`, `assets/manifest.json` and the matching component and template.

Use Vesper Libre regular and bold, cream canvas, red accents and ink copy. Preserve the original logos. Do not import Protect Line fonts or colours. Use one mascot composition per page at most; publication permission and restricted swatches are documented in `brand/publication.md`.

For limited context, use `LLM_CONTEXT.md`; for a concrete brief, use `prompts/README.md`. Check desktop and mobile layouts and run `npm run check`. Never invent reviews, legal statements, premiums or cover guarantees.
