# Ready-to-use design briefs

First give the agent access to this repository. Ask it to read `AGENTS.md`, `DESIGN.md`, the token CSS, voice and asset manifest, then use one brief below.

## Landing page

> Create a Red life insurance landing page for [audience] with the purpose [goal]. Reuse templates/landing-page.html and the component styles. Cream-led composition, Vesper Libre, ink body copy, large red headline accents and one appropriate original mascot composition. Include a clear next action, balanced explanation, three simple steps and FAQ. Use supplied approved copy where available; mark missing product facts and footer wording. Test at 375px and 1440px. Report publication dependencies without stopping internal design work.

## Product explanation

> Build a Red page explaining [product] from this approved copy: [copy]. Reuse templates/product-page.html. Keep benefits and limitations equally readable. Do not invent eligibility, premiums, payout claims, reviews or insurer information. Explain unfamiliar terms once. Use one original illustration only if it supports the subject.

## Quote journey

> Design the interface for [quote step], using templates/quote-page.html and components/forms.html. Use persistent labels, appropriate input types, accurate progress, keyboard access, field-linked errors and an honest completion state. Here are the approved privacy/contact expectations: [source]. Keep layout design separate from the actual quoting/data service integration. Run the relevant validation.

## Presentation

> Create [number] Red slides explaining [topic], using templates/slide.html at 1280×720. One idea per slide, short sentence-case headline, cream canvas, Vesper Libre and red emphasis. Use supplied facts only. If illustration is helpful, at most one existing mascot composition per slide. Keep any publication-permission dependency in the handoff.

## Social creative

> Create a Red [square/portrait/story] creative for [message], using the matching template. Export at its documented dimensions. Use the supplied logo and no more than one appropriate original Red composition. Use this approved headline and CTA: [copy]. Do not fabricate an offer or testimonial. Keep text out of platform overlay areas and inspect the actual export.

## Email

> Adapt templates/email.html for [purpose]. Keep the 600px table layout, default palette, Georgia fallback, large bold red CTA and short British English copy. Here are the approved message, hosted image URLs, destination and required footer links: [source]. Highlight any missing item and review it in the intended email clients before sending.

## Review a design

> Compare this design against DESIGN.md. Check actual rendered fonts, palette, contrast, original asset paths, mascot count, layout at mobile/desktop and copy evidence. Fix deviations using the system rather than inventing new colours or fonts. Report remaining source dependencies precisely.
