# Vesper Libre

Bundled regular 400 and bold 700 match PDF page 6. TTF files are fetched from Google Fonts' Vesper Libre distribution; they are not synthetic weights. `colors_and_type.css` loads them locally with `font-display: swap`.

- Regular: https://fonts.gstatic.com/s/vesperlibre/v21/bx6CNxyWnf-uxPdXDHUD_Rd4Dw.ttf
- Bold: https://fonts.gstatic.com/s/vesperlibre/v21/bx6dNxyWnf-uxPdXDHUD_RdAs2Cp0g.ttf
- Licence: https://raw.githubusercontent.com/google/fonts/main/ofl/vesperlibre/OFL.txt
