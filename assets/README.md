## Usage

Preserve proportions and colours. Do not generate substitute logos or mascot poses. Use the red logo on cream and the white logo on red. Illustration colours do not authorise matching UI colours.

Mascot compositions, including partial hands/edge poses and scenes with Red, count towards the one-per-page maximum. Catalogue pages are a documented internal inventory exception. Babies and bubbles are contextual accents with their own permission requirement. Read [publication dependencies](../brand/publication.md).

Set original width/height attributes to prevent layout shift. Use fluid CSS sizing, `object-fit: contain` and empty alt text for decorative artwork. Provide factual alt text when meaning is not already in the copy.

For production, generate appropriately sized derivatives in the consuming project; do not ship multi-megabyte originals where a small render is sufficient. Preserve the source originals and document derivative provenance. No optimised or generated replacement is claimed as an original here.
