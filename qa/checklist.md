# Design review checklist

## Internal handoff

- [ ] Read order followed; sourced constraints distinguished from system defaults.
- [ ] Palette comes from tokens; restricted colours excluded unless explicitly permitted.
- [ ] Vesper Libre 400/700 actually renders; no synthetic font substitutions in final web/export.
- [ ] Logo original, proportional and given enough clear space.
- [ ] One mascot composition maximum; edge/partial art and scenes counted.
- [ ] Body/labels/links are ink on cream; red pairs are large text; CTA is at least 20px bold.
- [ ] Appropriate asset chosen; no invented illustration, reviews or claims.
- [ ] Mobile 320/375px, tablet 768px and desktop 1440px checked for overflow and reading order.
- [ ] Keyboard navigation, focus, menu open/close and native FAQs work.
- [ ] Form shows textual errors and honest non-submitting demo status.
- [ ] Reduced motion honoured; ordinary pages usable at 200% zoom.
- [ ] Artboards checked at documented export size; fonts and images fully loaded.
- [ ] `npm run check` passes and unresolved sources are visible.

## Before publishing a specific design

- [ ] Brand permissions for mascot, babies/bubbles or restricted swatches recorded where required.
- [ ] Product copy, limitations, reviews, offers, footer and contact routes verified for this campaign.
- [ ] Live forms and links correctly integrated and tested; demo copy removed appropriately.
- [ ] Email images hosted; privacy and unsubscribe links supplied if relevant; client rendering reviewed.

This list is a working release aid, not a claim that an internal template has already received external approval.
